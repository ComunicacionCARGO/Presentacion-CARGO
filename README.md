# Presentación Grupo CARGO

Presentación interactiva de Grupo CARGO. Es un sitio estático (HTML, CSS y JavaScript, sin instalar nada) publicado con GitHub Pages.

## Ver la presentación

- **En la computadora:** doble clic en `index.html` (Chrome o Edge, en pantalla completa con F11).
- **En internet:** desde la dirección de GitHub Pages del repositorio.

## Editar textos y datos

Los textos, cartas y datos se cambian en la carpeta `datos/`, con el Bloc de notas. La guía paso a paso está en **`LEEME - Como editar las cartas.txt`**.

## Estructura

| Carpeta | Contenido |
|---|---|
| `datos/` | Textos y datos editables |
| `img/` | Imágenes |
| `landing/` | Portada con el carrusel de cartas |
| `slides/` | Una carpeta por diapositiva |
| `compartido/` | Colores, tipografías, transiciones y scroll comunes |
| `herramientas/` | Scripts de desarrollo (servidor local, extracción del mapa); no forman parte del sitio |

`CLAUDE.md` contiene el contexto técnico del proyecto para trabajar con Claude.

Los contornos del mapa provienen de [Natural Earth](https://www.naturalearthdata.com/) (dominio público).
